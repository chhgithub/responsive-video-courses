## 1. 项目概述

### 1.1 项目简介

本项目是一个**响应式视频课程学习平台**，包含前台网站和后台管理系统两大子系统。

- **前台网站**: 面向普通用户，提供课程浏览、购买、学习、咨询、通识教育等功能
- **后台管理**: 面向管理员，提供课程管理、订单管理、用户管理、数据统计等功能

### 1.2 核心功能模块

```
video-course-platform/
├── 前台网站 (Portal)
│   ├── 课程中心 - 课程列表、课程详情、学习页面
│   ├── 用户中心 - 注册登录、个人资料、我的课程、学习记录
│   ├── 咨询服务 - 在线咨询表单、咨询记录
│   ├── 通识教育 - 家庭教育、校园教育、课程兑换
│   ├── 资讯公告 - 新闻、活动、热点话题
│   └── 关于我们 - 关于学校、关于讲师、关于研究
│
└── 后台管理 (Admin)
    ├── 仪表盘 - 数据统计、快速操作
    ├── 首页管理 - 轮播图、新闻、活动、热点
    ├── 课程中心 - 课程管理、课程套餐、课程评价
    ├── 订单管理 - 订单列表、订单详情
    ├── 讲师管理 - 讲师列表、讲师展示
    ├── 系统管理 - 用户管理、标签管理、群发消息、角色权限
    ├── 通识教育 - 单位信息、学员管理、兑换码管理、学习进度
    └── 关于我们 - 关于学校、关于讲师、关于研究、联系方式
```

## 3. 数据存储架构

### 3.1 数据存储策略

本项目使用 **localStorage** 进行数据持久化，采用模块化设计：

```
utils/
├── 用户数据
│   ├── user-storage.ts            # 用户注册、登录、信息管理
│   └── auth.ts (stores)         # 认证状态
│
├── 课程数据
│   ├── course-storage.ts          # 课程、章节、课时管理
│   ├── learning-storage.ts        # 学习记录（统一）
│   └── course-package-storage.ts # 课程套餐
│
├── 订单数据
│   └── order-storage.ts           # 订单管理（支持单课程和套餐）
│
├── 咨询与消息
│   ├── consultation-storage.ts     # 在线咨询、咨询回复
│   ├── message-storage.ts         # 消息中心、群发消息
│   └── broadcast-storage.ts        # 群发消息记录
│
├── 标签系统
│   └── user-tag-storage.ts        # 用户标签管理
│
├── 通识教育
│   └── general-education-storage.ts # 单位、学员、兑换码、学习进度
│
└── 内容管理
    ├── banner-storage.ts           # 轮播图
    ├── news-storage.ts            # 新闻、活动、热点
    └── cert-storage.ts            # 证书管理
```

### 3.2 数据存储设计原则

1. **模块化隔离**: 每个功能模块独立的存储文件
2. **统一接口**: `course-storage.ts` 中的课程接口被 `portal-course-adapter.ts` 适配
3. **数据一致性**: 购买后自动创建学习记录，确保数据同步
4. **默认数据**: 每个存储模块提供默认数据，首次运行自动初始化

## 4. 核心业务流程

### 4.1 用户注册与登录流程

```
用户注册流程:
┌─────────────────────┐
│  1. 访问注册页面   │
│     └─> /portal/register  │
│                          │
│  2. 填写注册信息      │
│     - 用户名*          │
│     - 密码*            │
│     - 昵称*            │
│     - 手机号*          │
│     - 邮箱*            │
│     - 单位管理员可绑定单位ID │
│                          │
│  3. 提交注册        │
│     └─> 校验用户名、手机号唯一性 │
│                          │
│  4. 保存用户信息      │
│     └─> user-storage.ts  │
│       - registerUser()  │
│                          │
│  5. 自动登录          │
│     └─> 设置认证状态  │
│       - setToken()       │
│       - setUserInfo()     │
│                          │
└─────────────────────┘

用户登录流程:
┌─────────────────────┐
│  1. 访问登录页面    │
│     └─> /portal/login      │
│                          │
│  2. 输入登录凭证      │
│     - 支持用户名或手机号 │
│     - 输入密码            │
│                          │
│  3. 提交登录        │
│     └─> user-storage.ts  │
│       - loginUser()      │
│                          │
│  4. 校验凭证          │
│     └─> 验证用户存在性 │
│     └─> 验证密码正确性  │
│                          │
│  5. 保存认证状态      │
│     └─> stores/auth.ts  │
│       - setToken()       │
│       - setUserInfo()     │
│       - initAuth()       │
│                          │
│  6. 跳转到首页/原页面  │
│     └─> 根据 redirect 参数  │
│                          │
└─────────────────────┘
```

**涉及文件**:
- `src/views/portal/register.vue` - 注册页面
- `src/views/portal/login.vue` - 登录页面
- `src/utils/user-storage.ts` - 用户数据存储
- `src/stores/modules/auth.ts` - 认证状态管理

## 9. 数据流转说明

### 9.1 用户数据流转

```
注册 → user-storage.ts: registerUser()
     ↓
登录 → stores/auth.ts: loginUser()
     ↓
个人信息管理 → user-storage.ts: updateUser()
     ↓
标签关联 → user-tag-storage.ts: tagUser()
     ↓
消息接收 → message-storage.ts: broadcastMessage()
```

### 9.2 订单数据流转

```
创建订单 → order-storage.ts: createOrder()
  - 单课程: type='course'
  - 套餐: type='package'
     ↓
支付订单 → order-storage.ts: payOrder()
  - 更新状态: pending → paid
  - 记录支付时间
     ↓
创建学习记录 → learning-storage.ts: addLearningRecord()
  - 单课程: 创建1个学习记录
  - 套餐: 创建N个学习记录（套餐中的所有课程）
     ↓
课程学习 → learning-storage.ts: updateLearningProgress()
  - 更新进度、完成状态、观看时长
```

### 9.3 咨询数据流转

```
用户提交咨询 → consultation-storage.ts: addConsultation()
  - 状态: pending
  - 关联 userId（已登录）
     ↓
管理员查看 → consultation-storage.ts: getAllConsultations()
     ↓
管理员回复 → consultation-storage.ts: addReplyRecord()
  - 回复方式: online 或 phone
  - 电话回复包含: callDuration, callStatus
     ↓
发送消息通知 → message-storage.ts: sendMessageToUser()
  - type: 'consultation'
  - 标题: 咨询回复通知
     ↓
用户查看消息 → message-storage.ts: getUserMessages()
  - 点击消息标记已读
     ↓
更新咨询状态 → consultation-storage.ts: updateConsultationStatus()
  - 状态: pending → replied
```

### 9.4 课程评价数据流转

```
用户提交评价 → course-storage.ts: addReview()
  - 默认状态: 'pending' (待审核)
     ↓
管理员审核 → course-storage.ts: auditReview()
  - 通过: status='approved'
  - 拒绝: status='rejected', 填写拒绝原因
  - 记录审核人和时间
     ↓
用户查看评价 → portal-course-adapter.ts: filter
  - 只显示已通过的评价: status='approved'
     ↓
管理员回复评价 → course-storage.ts: replyReview()
  - 回复内容
  - 回复时间
```

1. **LocalStorage 限制**: LocalStorage 有 5-10MB 大小限制，注意存储数据量
2. **数据类型**: 所有存储数据必须可序列化为 JSON
3. **数据安全**: 避免在 LocalStorage 中存储敏感信息（如明文密码）
4. **数据备份**: 建议实现数据备份和恢复机制
5. **错误处理**: 所有 localStorage 操作需要 try-catch 包裹

### 10.2 开发规范建议

1. **TypeScript 严格模式**: 启用 `strict: true`，确保类型安全
2. **命名规范**:
   - 组件: PascalCase (如 `CourseCard.vue`)
   - 函数: camelCase (如 `getUserInfo`)
   - 常量: UPPER_SNAKE_CASE (如 `API_BASE_URL`)
   - 接口: PascalCase (如 `User`)
3. **代码组织**: 按功能模块划分目录，保持单一职责
4. **注释规范**: 复杂逻辑必须添加注释说明
5. **组件拆分**: 大型组件拆分为多个小组件
6. **样式隔离**: 使用 Scoped CSS，避免全局污染
7. **状态管理**: 全局状态放在 Pinia Store，组件内使用 ref 管理本地状态
8. **错误处理**: 统一的错误处理机制，用户友好的错误提示
9. **性能优化**: 列表使用虚拟滚动，图片懒加载
10. **响应式设计**: 使用 Element Plus 的响应式组件，适配移动端

## 12. 常见问题与解决方案

### 12.1 常见问题

**Q1: 如何添加新的课程章节？**
A: 使用后台管理系统的课程管理 → 章节管理 → 课时管理功能

**Q2: 如何修改课程价格？**
A: 课程管理 → 编辑课程 → 修改价格字段 → 保存

**Q3: 用户如何学习课程？**
A: 课程中心 → 购买课程 → 支付成功 → 我的课程 → 点击学习

**Q4: 如何创建课程套餐？**
A: 后台课程管理 → 课程套餐 → 添加课程到套餐 → 设置价格和折扣

**Q5: 如何群发消息？**
A: 后台系统管理 → 群发消息 → 选择目标（标签/课程/单位/全员）→ 编写消息 → 发送

**Q6: 如何查看咨询回复？**
A: 后台首页 → 咨询管理 → 点击详情 → 查看回复记录

**Q7: 课程评价为什么不显示？**
A: 后台课程管理 → 评价审核 → 确保状态为 `approved`（已通过）

**Q8: 学习记录如何统计？**
A: 从 `learning-storage.ts` 获取学习记录，统计学习时长、完成进度

#### 单位管理员数据来源说明：

单位管理员登录后，系统根据其绑定的单位ID（authStore.userInfo.organizationId）进行数据隔离和过滤。

**学员管理** (`/admin/org/students`)：
- **数据来源**：getOrgStudents() (从 @/api/organization.ts)
- **获取逻辑**：
  1. 从 user-storage.ts 获取所有用户
  2. 使用 filterByOrg() 过滤出角色为 student 且 organizationId 匹配的用户
- **展示内容**：
  - 用户列表（姓名、手机号、邮箱）
  - 是否已激活（通过 getUserRedeemedCourses() 查询激活的课程数量）
  - 已激活课程数（访问权限不为空且未过期）
- **学员详情**：点击用户可查看详细信息
- **跳转学习进度**：可跳转到学习进度页面查看该用户的所有课程进度

**兑换码管理** (`/admin/general/redemption`)：
- **数据来源**：getOrgRedemptionCodes() (从 @/api/organization.ts)
- **获取逻辑**：
  1. 从 general-education-storage.ts 获取所有兑换码
  2. 使用 filterByOrg() 过滤出 organizationId 匹配的兑换码
- **展示内容**：
  - 兑换码列表（编码、名称、类型、有效期）
  - 使用状态（未使用/已使用/已过期）
  - 激活时间
  - 使用记录（用户ID、使用时间、课程/套餐）
- **统计信息**：总数、未使用数、已使用数、已过期数
- **创建兑换码**：管理员可创建新兑换码，分配给指定单位

**学习进度** (`/admin/org/progress`)：
- **数据来源**：getOrgStudentProgress() (从 @/api/organization.ts)
- **获取逻辑**：
  1. 从 general-education-storage.ts 获取所有课程访问权限 (getUserCourseAccess())
  2. 使用 filterByOrg() 过滤出 organizationId 匹配的访问记录
  3. 关联课程信息（从 getPublishedCourses() 获取课程详情）
- **展示内容**：
  - 用户列表（可按用户筛选）
  - 每个用户的课程学习进度
  - 进度信息：课程ID、课程名称、进度百分比、最后学习时间、过期时间
  - **进度计算**：注意：当前使用 calculateProgress() 返回模拟数据（随机数）
  - 实际开发时：需要从 learning-storage.ts 获取真实的学习记录并计算进度
  - **统计信息**：总学员数、已激活学员数、学习总访问数

#### 数据流程示意：

用户存储 (user-storage.ts)
       ↓
   所有用户 (含 student 角色)
       ↓
权限过滤 (permission-filter.ts)
   单位管理员登录时 + organizationId
       ↓
   ├─→ 学员列表 (roles='student' + organizationId 匹配)
   │    └─→ 查询激活记录 (getUserRedeemedCourses)
   │
   ├─→ 兑换码列表 (organizationId 匹配)
   │    └─→ 过滤所有兑换码
   │
   └─→ 学习进度 (organizationId 匹配)
            └─→ 课程访问权限 (getUserCourseAccess) + 课程信息 (getPublishedCourses)
