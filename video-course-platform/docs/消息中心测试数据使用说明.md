# 消息中心测试数据使用说明

## 概述

本工具用于快速初始化消息中心的测试数据，方便原型展示和功能演示。

## 包含的数据类型

### 1. 咨询回复
- **多轮对话示例**：关于Python基础课程的咨询，包含学员提问和讲师的多条回复
- **单次回复示例**：机器学习课程咨询
- **未回复示例**：课程证书认证问题

### 2. 系统通知
- 系统维护通知（高优先级）
- 课程进度同步提醒
- 账号安全提醒（高优先级）
- 新章节上线通知
- 支付成功通知

### 3. 公告
- 平台升级通知（高优先级）
- 春季特惠活动
- 新课程上线
- 学习进度排行榜活动

## 使用方法

### 方法一：使用开发工具（推荐）

1. 启动开发服务器：`npm run dev`

2. 在浏览器中访问应用（开发环境会自动显示开发工具）

3. 点击页面右下角的蓝色圆形按钮（设置图标）

4. 在弹出的开发工具面板中：
   - 点击"初始化测试数据"按钮
   - 等待数据初始化完成
   - 刷新页面
   - 进入"消息中心"查看效果

5. 如需清空测试数据，点击"清空测试数据"按钮

### 方法二：在浏览器控制台运行代码

1. 打开浏览器控制台（按 F12）

2. 粘贴以下代码并回车：

```javascript
// 获取当前用户ID（根据实际情况调整）
const userId = 'mock_user_001';

// 初始化测试数据
fetch('/src/utils/mock-message-data.js')
  .then(res => res.text())
  .then(code => {
    const module = { exports: {} };
    const exports = module.exports;
    eval(code);
    exports.initMockMessageData();
    console.log('测试消息数据初始化完成！');
    setTimeout(() => location.reload(), 500);
  });
```

3. 刷新页面后进入消息中心查看

### 方法三：在代码中直接调用

在 `main.ts` 或 `App.vue` 的 `onMounted` 中添加：

```typescript
import { isMockDataInitialized, initMockMessageData, setMockDataInitialized } from '@/utils/mock-message-data';

onMounted(() => {
  // 只在开发环境且未初始化时执行
  if (import.meta.env.DEV && !isMockDataInitialized()) {
    initMockMessageData();
    setMockDataInitialized();
  }
});
```

## 数据结构

### 消息类型 (MessageType)
- `system` - 系统通知
- `consultation` - 咨询回复
- `course` - 课程相关
- `order` - 订单相关
- `announcement` - 公告

### 消息状态 (MessageStatus)
- `unread` - 未读
- `read` - 已读
- `deleted` - 已删除

### 优先级 (Priority)
- `low` - 低
- `normal` - 中等
- `high` - 高

## 自定义测试数据

如果需要添加自定义测试数据，可以编辑 `src/utils/mock-message-data.ts` 文件：

```typescript
import { sendMessageToUser } from './message-storage';

function addCustomMessage() {
  sendMessageToUser({
    userId: 'your_user_id',
    type: 'consultation', // 或 'system', 'announcement' 等
    title: '自定义消息标题',
    content: '自定义消息内容',
    priority: 'normal', // 或 'low', 'high'
    sourceId: 'optional_source_id',
    sourceType: 'optional_source_type',
    actionUrl: 'optional_action_url',
  });
}
```

## 注意事项

1. 测试数据存储在浏览器的 `localStorage` 中，key 为 `user_messages`

2. 清除浏览器缓存会删除测试数据

3. 开发工具仅在开发环境（`import.meta.env.DEV === true`）下显示

4. 初始化测试数据会先清空当前用户的所有消息

5. Mock用户ID默认为 `mock_user_001`，如需调整请修改 `mock-message-data.ts` 中的 `MOCK_USER_ID` 常量

## 文件说明

- `src/utils/message-storage.ts` - 消息存储工具类
- `src/utils/mock-message-data.ts` - 测试数据初始化脚本
- `src/components/DevTools.vue` - 开发工具组件
- `src/views/member/message/index.vue` - 消息中心页面

## 故障排查

### 问题：点击"初始化测试数据"后没有效果

**解决方案**：
1. 检查浏览器控制台是否有错误信息
2. 确认当前用户ID是否正确
3. 尝试清除 localStorage 后重新初始化

### 问题：消息中心看不到测试数据

**解决方案**：
1. 确认已刷新页面
2. 检查当前用户ID是否与测试数据中的用户ID一致
3. 在开发工具面板查看"数据统计"确认数据是否创建成功

### 问题：开发工具按钮不显示

**解决方案**：
1. 确认是否在开发环境运行
2. 检查 `App.vue` 中是否正确引入了 `DevTools` 组件
3. 清除浏览器缓存后重新加载
