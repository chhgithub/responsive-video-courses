# 资源编辑权限和影响范围分析

---

## 一、课程

### 编辑权限

| 状态 | 可编辑内容 | 删除限制 |
|------|-----------|---------|
| 草稿 | 全部内容 | 可直接删除 |
| 已发布 | 全部内容 | 需检查是否有已支付订单 |
| 已下架 | 全部内容 | 需检查是否有已支付订单 |

### 修改影响范围

| 模块 | 实时生效 | 说明 |
|------|---------|------|
| 首页搜索/课程列表 | ✅ | 修改名称、封面、价格等立即体现 |
| 课程详情页 | ✅ | 所有修改实时更新 |
| 学习页面 | ✅ | 课程名称、封面实时更新；章节结构修改可能影响学习进度 |
| 我的订单 | 部分 | 名称、封面实时更新；价格保持购买时的历史价格 |
| 我的收藏 | ✅ | 实时显示最新信息 |
| 套餐中的课程 | ✅ | 套餐页显示的课程信息实时更新 |
| 兑换记录 | ✅ | 显示最新的课程名称等信息 |
| 学习进度 | ❌ | 已有学习记录不受课程内容修改影响 |

### 编辑建议

- **价格调整**：在草稿状态下完成，确认后再发布
- **内容大改**：建议创建新版本，原版本下架保持稳定
- **删除课程**：必须先检查是否有订单、套餐关联、兑换码关联

## 二、套餐

### 编辑权限

| 状态 | 可编辑内容 | 删除限制 |
|------|-----------|---------|
| 草稿 | 全部内容 | 可直接删除 |
| 已发布 | 全部内容 | 需检查是否有学员在学习 |
| 已下架 | 全部内容 | 需检查是否有学员在学习 |

### 修改影响范围

| 模块 | 实时生效 | 说明 |
|------|---------|------|
| 套餐列表 | ✅ | 所有修改立即体现 |
| 套餐详情页 | ✅ | 所有修改实时更新 |
| 课程详情页（相关套餐） | ✅ | 添加/移除课程后实时更新 |
| 我的订单 | 部分 | 名称、封面、包含课程实时更新；价格保持历史价格 |
| 已购用户的套餐 | ❌ | 按购买时的套餐内容执行 |
| 添加课程 | ✅ | 已购用户自动获得新课程 |
| 移除课程 | 部分 | 有学习记录的保留，无记录的直接移除 |
| 必修/选修修改 | 部分 | 影响学习进度计算，已完成课程不受影响 |

### 编辑建议

- **添加课程**：直接添加，已购用户自动获得
- **移除课程**：慎重操作，确认无学习记录后再移除
- **价格调整**：在草稿状态下完成后再发布

## 三、兑换码

### 编辑权限

| 状态 | 可编辑内容 | 说明 |
|------|-----------|------|
| 未使用 | 全部内容 | 可删除、可下架 |
| 已使用 | 仅备注 | 其他字段不可修改 |
| 已过期 | 仅备注 | 其他字段不可修改 |
| 已下架 | 仅备注、可重新上架 | 重新上架后可再次使用 |

### 修改影响范围

| 模块 | 实时生效 | 说明 |
|------|---------|------|
| 兑换页面 | ✅ | 下架后无法兑换，过期时间修改立即生效 |
| 兑换记录 | 部分 | 名称、单位名称实时更新；兑换时间、有效期保持原值 |
| 我的订单（兑换） | 部分 | 显示最新名称信息；兑换记录保持原值 |
| 学习权限检查 | ❌ | 基于兑换记录计算，不受兑换码后续修改影响 |
| 过期计算 | ❌ | 按 redeemTime + accessValidDays 计算，使用兑换时的值 |

### 编辑建议

- **延长有效期**：在未使用状态下修改
- **停止兑换**：将未使用的兑换码下架（不影响已兑换用户）
- **重新启用**：将已下架的兑换码重新上架

## 四、关键对比：订单进入 vs 首页搜索进入

### 订单进入课程

```
我的订单 → 点击课程/套餐 → 课程详情页 → 学习/再次购买
```

**特点：**
- 价格：显示购买时的历史价格
- 课程信息：实时更新（名称、封面等）
- 可访问性：已购用户直接访问，无状态限制
- 套餐课程：显示购买时快照（学习记录中的课程列表）
- 推荐套餐：无

**适用场景：**
- 快速访问已购课程
- 查看历史购买记录

### 首页搜索进入课程

```
首页搜索 → 课程列表 → 点击课程 → 课程详情页 → 购买/学习
```

**特点：**
- 价格：显示当前最新价格
- 课程信息：实时最新
- 可访问性：需要检查购买状态
- 课程状态：只能看到已发布课程
- 推荐套餐：显示相关套餐

**适用场景：**
- 发现和购买新课程
- 浏览课程目录

### 核心差异表

| 维度 | 订单进入 | 搜索进入 |
|------|---------|---------|
| 价格 | 购买时的历史价格 | 当前最新价格 |
| 课程信息 | 动态更新 | 实时最新 |
| 可访问性 | 已购用户直接访问 | 需检查购买状态 |
| 课程状态 | 无限制（即使下架） | 只显示已发布 |
| 套餐课程 | 购买时快照 | 实时最新 |
| 推荐套餐 | 无 | 显示相关套餐 |

## 五、资源状态流转

### 课程状态

```
draft → published → offline
         ↓           ↓
      可下架      可下架
```

- **draft**: 仅管理员可见，用户无法搜索和购买
- **published**: 所有用户可见，可搜索、可购买
- **offline**: 新用户无法购买，已购用户不受影响

### 套餐状态

```
draft → published → offline
         ↓           ↓
      可下架      可下架
```

- **draft**: 仅管理员可见
- **published**: 所有用户可见
- **offline**: 新用户无法购买，已购用户不受影响

### 兑换码状态

```
unused → used → expired
   ↓        ↓
offline
```

- **unused** → **used**: 用户兑换时
- **unused** → **expired**: 超过过期时间
- **unused** → **offline**: 管理员下架
- **offline** → **unused**: 管理员重新上架

## 六、资源关联关系

```
课程
  ├─ 被 多个 套餐 引用
  ├─ 被 兑换码 绑定
  ├─ 产生 订单
  ├─ 有 学习记录
  └─ 有 评价

套餐
  ├─ 包含 多个 课程
  ├─ 产生 订单
  ├─ 有 学习记录
  └─ 有 评价

兑换码
  ├─ 绑定 课程 或 套餐
  ├─ 创建 订单（兑换类型）
  └─ 产生 兑换记录

订单
  ├─ 关联 课程 或 套餐
  ├─ 有 退款记录（可选）
  └─ 决定 学习权限

兑换记录
  ├─ 关联 课程 或 套餐
  ├─ 关联 兑换码
  └─ 决定学习有效期
```

## 七、重要规则总结

### 价格相关

| 场景 | 规则 |
|------|------|
| 课程价格修改 | 不影响历史订单，影响新购买用户 |
| 套餐价格修改 | 不影响历史订单，影响新购买用户 |
| 课程原价修改 | 影响套餐原价（套餐价格需重新计算） |
| 订单价格 | 创建时快照保存，永久不变 |

### 权限相关

| 场景 | 规则 |
|------|------|
| 课程下架 | 已购用户可继续学习 |
| 套餐下架 | 已购用户可继续学习 |
| 兑换码下架 | 不影响已兑换用户 |
| 免费改付费 | 已学习用户仍可继续 |
| 付费改免费 | 所有用户都可学习 |

### 内容相关

| 场景 | 规则 |
|------|------|
| 课程章节修改 | 不影响已完成课时的记录 |
| 章节顺序调整 | 不影响学习进度 |
| 删除章节 | 对应学习记录可能失效 |
| 套餐添加课程 | 已购用户自动获得新课程 |
| 套餐移除课程 | 有学习记录的保留，无记录的移除 |

### 有效期相关

| 场景 | 规则 |
|------|------|
| 课程有效期修改 | 新购买用户生效，已购用户按购买时计算 |
| 套餐有效期修改 | 新购买用户生效，已购用户按购买时计算 |
| 兑换码有效期修改 | 未使用的生效，已兑换的按兑换时计算 |
| 学习过期计算 | 基于 redeemTime + accessValidDays（兑换时的值） |

## 八、编辑操作影响图

### 课程修改

```
修改课程信息
    │
    ├─→ 首页搜索：实时更新 ✅
    ├─→ 课程详情：实时更新 ✅
    ├─→ 学习页面：实时更新 ✅（章节修改可能影响进度）
    ├─→ 我的订单：名称/封面实时更新，价格不变 ❌
    ├─→ 我的收藏：实时更新 ✅
    ├─→ 套餐中：实时更新 ✅
    ├─→ 兑换记录：实时更新 ✅
    └─→ 学习进度：不受影响 ❌
```

### 套餐修改

```
修改套餐信息
    │
    ├─→ 套餐列表：实时更新 ✅
    ├─→ 套餐详情：实时更新 ✅
    ├─→ 课程详情（相关套餐）：实时更新 ✅
    ├─→ 我的订单：名称/封面/课程列表实时更新，价格不变 ❌
    ├─→ 已购用户套餐：按购买时执行 ❌
    ├─→ 添加课程：已购用户自动获得 ✅

```

```
    │
    ├─→ 兑换页面：实时更新 ✅

    ├─→ 过期时间修改：未使用的生效 ✅
    ├─→ 兑换记录：名称实时更新，时间/有效期不变 ❌
    ├─→ 我的订单：名称实时更新，兑换记录不变 ❌
    └─→ 学习权限：基于兑换记录，不受后续修改影响 ❌
```

## 九、注意事项

### 删除操作

- **课程删除**：检查订单、套餐关联、兑换码关联
- **套餐删除**：检查是否有学员在学习
- **兑换码删除**：只能删除未使用的

### 风险操作

- **删除章节**：可能导致学习记录失效
- **移除套餐课程**：可能影响已购用户的课程列表
- **课程状态大幅调整**：可能影响用户购买决策

### 推荐做法

1. 重要修改前在草稿状态完成测试
2. 大幅内容变更考虑创建新版本
3. 价格调整提前通知用户
4. 删除操作始终检查关联数据
5. 修改后进行完整流程测试
